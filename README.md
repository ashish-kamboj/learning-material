## Overview
This repository collects study materials, question banks, ebooks, and course links for data science and machine learning topics, plus practical references for Python, R, Spark, Docker, Kubernetes, and MLOps. It is intended as a personal learning hub and a sharable resource for others preparing for interviews or studying these topics.

## How to use
- Browse files directly on GitHub and open the linked markdown files for topic-specific content.
- Download the Excel checklist directly from the repository if you want an editable copy.
- Use your browser's search (Ctrl/Cmd+F) on longer markdown files to quickly find topics or questions.
- If you want to use these materials for interview prep, start with the question banks and then consult the ebooks or course links for deeper study.
